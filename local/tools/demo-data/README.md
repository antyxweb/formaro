# Демо-данные

Демо-партнёр «Спецодежда Плюс» и демо-покупатель «Тестовый Тест Тестович».

| Роль | Логин (e-mail) | Где входить |
|---|---|---|
| Партнёр «Спецодежда Плюс» (Петров Иван) | demo-partner@example.test | /cabinet/ |
| Покупатель Тестовый Тест Тестович | test-buyer@example.test | вход на сайте, /personal/ |

Пароли — в `config.php` (в git не хранится; пример — `config.example.php`).

Что создаётся (`seed.php`):
- партнёр: проверен, показывается на сайте, логотип, обложка, реквизиты, контакты;
- категории партнёра: «Одежда для пищевых производств», «Утеплённые жилеты»
  (допущены), «Одежда для клининга» (на проверке);
- 8 товаров с картинками, ценами, остатками;
- скидки: 10% на зимнюю спецодежду, −15% на перчатки от 50 пар; купон SPECPLUS15;
- 2 новости партнёра с привязкой к каталогу;
- 5 заказов покупателя: выполнен, отправлен (оба оплачены), в обработке,
  новый, отменён — с историей;
- 4 диалога покупателя с партнёром (по заказу, по товару, общие);
- 2 обращения в техподдержку (закрытое с ответом и открытое);
- финансы: поступления, комиссия, выплата и заявка на вывод в обработке;
- уведомления партнёру и покупателю.

Команды (в контейнере php):

    php /opt/www/local/tools/demo-data/seed.php    # создать (если партнёра ещё нет)
    php /opt/www/local/tools/demo-data/clean.php   # удалить всё демо

Перед переносом сайта на рабочий сервер демо лучше удалить (`clean.php`).
